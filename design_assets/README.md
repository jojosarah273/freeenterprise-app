# Design source assets

Originals used to build the app's FF4-style UI. Copies are baked into the app at
build time under `app/src/main/assets/`.

| File | Used as | Origin | Licence |
|---|---|---|---|
| `font_ff4.ttf` | `app/src/main/assets/fonts/ff4.ttf` | Reproduction of the game's typeface by the FontStruct user **`gameboyf9`** | **Third-party** — creator's own copyright, per [FontStruct's terms](https://fontstruct.com/terms). Not MIT. Confirm the font's licence before publishing. |
| `POINTER.png` | `app/src/main/assets/ff4/pointer.png` | **Hand-made by jojosarah273** | **MIT**, same as this project |

Both are **reproductions** — independently recreated, not extracted from the
game. See `THIRD_PARTY_NOTICES.md` for the full picture and the pre-release
action item on the font.

unaffiliated.
