# Design source assets

Originals used to build the app's FF4-style UI. Copies are baked into the app at
build time under `app/src/main/assets/`.

| File | Used as | Notes |
|---|---|---|
| `font_ff4.ttf` | `app/src/main/assets/fonts/ff4.ttf` | "Final Fantasy IV Regular" — the game's in-game font. **Third-party game asset.** |
| `POINTER.png` | `app/src/main/assets/ff4/pointer.png` | The game's menu cursor sprite. **Third-party game asset.** |

Both are ripped from the original game and are not covered by this project's
licence or by Free Enterprise's MIT licence. See `THIRD_PARTY_NOTICES.md`.
